  #3  "Unhandled Rejection"  Timeout calling "onTaskUpdate"

      NO origin line at all. Not bound to any test file.

#4 is the one that is not a lost test result. Different header
("Unhandled Error", not "Unhandled Rejection"), no file attribution: it is

association. Same root cause as #1-#3, but it never corresponded to a test.

This is why 4 errors sat against a 3-result shortfall (4624 reported vs 4627
collected). The arithmetic is not a coincidence: 3 attributed errors, 3
missing results, 1 unattributed error. When applying the Errors-bucket rule,
read the header and look for the "This error originated in" line -- an entry
lacking one is infrastructure noise, not a test that vanished.

Consequence for Phase 6 -- READ THE LINE NUMBER, THE PREDICTION IS TWO-SIDED.

The mutated tree was a natural experiment. It ran 2c's data against a loader
that could not yet read the new column, and that is exactly the state the
Phase X gate exists to prevent: five Initiatives rejected at intake, line 13
firing at 24 instead of 29. The failure mode the gate was argued for is now
demonstrated rather than argued, and this file is where it showed up.

So matrix.referenceSeed.test.js is an INTEGRATION CANARY for the gate. It
exercises the load path; the four mutation tests exercise the reducer. That
is the stronger of the two signals, and they are not redundant.

Under the gated sequence the loader accepts the five Initiatives, line 13
holds at 29, and execution reaches line 20.

REQUIRED, NOT OPTIONAL: the commit that adds the artifact rows to
tests/fixtures/reference_matrix_v3_0.json MUST also move the expected count
to 188 in the SAME commit. Three occurrences, all in
tests/state/matrix.referenceSeed.test.js:

    line 11  comment  "... / 63 Deliverable / 175 Artifact / 10 System."
    line 18  comment  "and all 175 Artifacts are valid and loaded ..."
    line 20  ASSERT   expect(Object.keys(m.artifactsById)).toHaveLength(175);

Do not split these across two commits. Splitting them means green signals
failure for however long the gap lasts, and it leaves referenceSeed sitting
