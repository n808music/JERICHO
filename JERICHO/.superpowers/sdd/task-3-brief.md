## Data Structure Details

### `pendingQuestions` (Array)

Each question object:
```javascript
{
  id: '4f3a2b1c...',                  // Generated by generateQuestionId(sourceIds, targetDate)
  sourceIds: ['d1', 'd2'],            // Sorted alphabetically
  targetDate: '2026-09-15',           // ISO date string
  detectedAtISO: '2026-08-06T10:00:00Z'  // When detection first surfaced this question
}
```

### `answered` (Object/Map)

Key: questionId, Value:
```javascript
{
  disposition: 'Declared' | 'DeadlineAlignment',  // Operator's choice
  recordedAtISO: '2026-08-06T10:30:00Z'          // When operator responded
}
```

### `lastComputedFrom` (Object)

Stores hashes of the matrix registries as they were when detection last ran:
```javascript
{
  deliverablesById: 'abc123def456...',    // stableHashObject(matrix.deliverablesById)
  artifactsById: 'xyz789uvw012...',       // stableHashObject(matrix.artifactsById)
  dependenciesById: 'ijk345lmn678...',    // stableHashObject(matrix.dependenciesById)
  convergenceEdgesById: 'opq901rst234...' // stableHashObject(matrix.convergenceEdgesById)
}
```
