## Engine-unification investigation (2026-07-18, DEFERRED — its own next-wave initiative)

Started the "engine-loop follow-up" to light up live Entity/Initiative/Project isolation. Scoped it minimal (enrich live calendar blocks with matrix identity) — **found infeasible**; then chose "link lanes→matrix at generation" — **also found infeasible**. Root: the plan model (goal-classification **lanes** — domain families like `product_software`/`creative_media`/`income_stream`) and the matrix model (intake **nodes** — Global-State entities/initiatives/projects) are **disjoint by design; no shared join key.**

Four candidate join signals checked, all empty for family/domain classification:
1. Live block `deliverableId` = `masterplan-deliverable:<laneId>` (synthetic, not a matrix artifact) — `fullHorizonScheduleExpansion.js:1219`.
2. Plan lanes carry only `domain`/`laneTitle` — no matrix ref.
3. Matrix **projects** have `role_tags=null`; **initiatives** carry structural tags only (`["system"]`/`["project"]`) — no family signal.
4. `deterministicPlanGenerator` steps carry `projectId` but **no `laneId`**; `defaultOwnerForLaneFamily` returns role labels ("Product Lead"), not matrix entities.

Both ways to force a join were **rejected as fabrication** (Attestation Contract): a hand-authored `entity→family` table hardcodes GSS-specific structure into a general intake engine (against Jericho's reusable premise); NLP-guessing families from node names manufactures a correspondence the data never asserts. **The only clean matrix identity on a schedule is `cycle.schedule.blocks`** (matrix-derived via `buildScheduledBlocksFromDeterministicResult` at `identityCompute.js:4292` — generated but unread; the comment there already names the "unified generateSchedule() engine, retiring GENERATE_COLD_PLAN/GENERATE_PLAN").

**Decision: DEFER.** This is the THIRD independent path to the same matrix→schedule unification wall (Gate 8 substrate + phase elicitation + this) → make engine unification its own scoped-and-gated **next-wave initiative** (adopt `cycle.schedule.blocks` as the calendar source), not absorbed piecemeal. "Adopt now" was declined mid-wave: it swaps the schedule source powering `Today` — materially bigger risk than Gates 5–8, which never touched execution. No code written (brainstorming HARD GATE held).
