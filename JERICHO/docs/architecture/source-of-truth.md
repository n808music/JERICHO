## Consolidation Guardrails

- One write path per artifact.
- All mirrors are adapter-only and must not be directly mutated by UI
  components.
- If a mirror diverges from canonical, canonical wins.
- Remove mirror reads only after regression tests for generation/apply/render
  pass.
- Mirror removal remains future work; current phase keeps adapter mirrors for
  compatibility surfaces.
